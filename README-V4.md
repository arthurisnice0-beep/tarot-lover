# Tarot Lover V4 · 沉浸式塔罗桌

## 本版升级
- 保留 V3 中国版/世界版、12题权重算法、结果页、测试码与海报功能。
- 答题页升级为沉浸式真实塔罗桌：暗紫天鹅绒、烛光、水晶氛围。
- 6 种牌阵循环：双牌、三牌、十字、四牌、月亮、扇形。
- 点击牌后执行上浮 → 翻牌 → 发光 → 自动进入下一题。
- 倒计时改为顶部金色细线，不再显示大数字。
- 开始按钮升级为“开始洗牌”，含 1.15 秒洗牌过渡。
- 最后一题结束后进入约 2.4 秒缘分信号读取。
- 生成图片已转为压缩 WebP 氛围背景并内置至 assets。

## 部署
将整个 `tarot-lover` 文件夹内容上传到 GitHub Pages 仓库根目录即可。

## 关键文件
- `index.html`：V4 页面结构
- `style.css`：V4 沉浸式视觉与 6 种牌阵
- `app.js`：V4 翻牌/倒计时/洗牌逻辑 + 原算法
- `assets/table-1.webp` ~ `table-6.webp`：塔罗桌氛围背景
- `assets/tarot-back.webp`：牌背纹理


## 商用授权（已开启）

- `REQUIRE_CODE: true`
- 每个授权码在同一浏览器最多生成 10 份报告。
- 中国版 / 世界版共用次数。
- 报告生成时扣 1 次，不会因为打开页面或中途退出而误扣。
- 授权码明文不放在网页源码中，`config.js` 仅保存 SHA-256 哈希。
- 商家明文码清单位于压缩包根目录 `商家授权码清单-不要上传到GitHub.txt`，部署时不要上传该文件。

> GitHub Pages 是纯前端。用户清理站点数据或换设备后，本机次数记录无法可靠延续；若要严格做到“一码只绑定一台设备、跨设备防复用”，需要接后端授权接口。

## V4.1 结果池扩容
- 中国版：48 个结果城市，覆盖大陆省会/直辖市，并补充深圳、苏州、宁波、青岛、厦门、大连、无锡、佛山、东莞、珠海、三亚、洛阳、开封、大理、桂林、香港、澳门等主要城市。
- 世界版：50 个国家，覆盖北美、拉美、欧洲、东亚、东南亚、南亚、中东、大洋洲及非洲主要目的地。
- 结果算法：先计算六维性格匹配，再在高匹配候选区间内使用基于 12 道答案序列的确定性分流；同一组答案始终得到同一结果，同时避免少数城市/国家长期占据绝大多数结果。


## V4.2 概率校准
- 中国结果池：48 城市；世界结果池：50 国家。
- 先按六维性格相似度进入高匹配候选池（中国 Top 18 / 世界 Top 22），再做确定性抽牌分流。
- 使用 1,000,000 条随机答题路径进行 Monte Carlo 校准。
- 主要城市/国家略高频，特色地点略低频；同一套答案结果固定，不使用每次刷新随机。
